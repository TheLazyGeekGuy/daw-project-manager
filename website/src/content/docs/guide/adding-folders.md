<p class="lead">Point the app at the folders your projects live in — it finds every project inside, however deep. Settings → Project Folders → <b>Add Folder</b>.</p>
<figure class="shot"><img src="/resources/screenshots/settings/settings-project-folders.png" alt="Settings, Project Folders: folders, excluded folders, recently deleted" loading="lazy" width="1920" height="1080"></figure>
<ul>
<li>Add the top folder (<code>~/Music</code>), not each song's.</li>
<li><b>Excluded folders</b> are skipped — templates, sample libraries.</li>
<li>Each folder has a scan mode: <b>Flat</b> (every project file is a project), <b>Smart Folder</b> (one subfolder per song) or <b>Version Stack</b> (one subfolder per song, its files stacked as <a href="/guide/version-stacks/">versions</a>).</li>
<li>Edit any profile's folders from here — the profile picker at the top.</li>
</ul>
