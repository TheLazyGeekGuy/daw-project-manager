<p class="lead">Free and open source. Pick your platform from the <a href="https://github.com/bandpassrecords/daw-project-manager/releases/latest">latest release</a>.</p>
<div class="platforms">
<div class="platform">
<img src="/resources/os/Windows_logo_-_2012.svg" alt="">

### Windows

<p>Microsoft Store, or the installer <b>.exe</b>. Not yet code-signed: <i>More info → Run anyway</i>. Installing a newer one upgrades in place.</p>
</div>
<div class="platform">
<img src="/resources/os/MacOS_logo_(2017).svg" alt="">

### macOS

<p>Open the <b>.dmg</b>, drag the app to Applications. If macOS warns: <i>System Settings → Privacy &amp; Security → Open Anyway</i>.</p>
</div>
<div class="platform">
<img src="/resources/os/Linux_logo.svg" alt="">

### Linux

<p><b>AppImage</b> (<code>chmod +x</code>, then run — updates itself), <b>Flatpak</b> (from <a href="https://flathub.org/en/apps/com.bandpassrecords.dpm">Flathub</a>) or <b>.tar.gz</b>. The Flatpak has no Google Drive sync: use <a href="/guide/local-backup/">local backup</a>.</p>
</div>
<div class="platform">
<img src="/resources/os/android-head.png" alt="">

### Android

<p>In closed testing on Google Play. Adds playlists and deadline notifications.</p>
</div>
