<p class="lead">How long has this song taken? In Session Mode you start a session on a project, and the time you work on it adds up: per session, and in total.</p>
<ol>
<li><b>Switch it on</b> — Settings → Work Sessions → <b>Session mode</b>. Off by default; in Normal Mode, launching a project just opens it in its DAW.</li>
<li><b>Start a session</b> — the bookmark button on a project's row (or <kbd>S</kbd>), then <b>Start Session</b>. The app asks before starting, switching or ending one, so the timer always means what you think.</li>
<li><b>Work</b> — the session bar at the top shows the song, its total so far and this session's time, with pause and stop. Its buttons open the project in its DAW or its page.</li>
</ol>

### Every session, on record

<p>A project's <b>Session History</b> lists each session — the day, when it started and ended, the phase the song was in, how long — and adds them up, then by phase: how long the song spent in arranging, in mixing. A session timed wrong can be edited or removed.</p>
<figure class="shot"><img src="/resources/screenshots/work-sessions/session-history.png" alt="A project's Session History: six sessions with their dates, times, phases and lengths, then work by phase" loading="lazy" width="1920" height="1080"><figcaption>Six sessions, <b>8h 0m</b> in all — and how that time splits across Idea, Arranging, Mixing and Mastering.</figcaption></figure>
<ul>
<li>A <a href="/guide/version-stacks/">version stack</a> adds up the time of all its versions.</li>
<li><b>Reminders</b> (Settings → Work Sessions) notify you at the interval you choose while a session runs, so one isn't left running by mistake.</li>
</ul>
