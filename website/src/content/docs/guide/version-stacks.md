<p class="lead">Song.flp, Song_2.flp, Song_3.flp: one song. Stack them and the library shows it once, with one set of notes, to-dos and work time.</p>
<ul>
<li>Select the versions → <b>Stack as Versions</b>, or set a folder's scan mode to <b>Version Stack</b> and every song folder stacks itself.</li>
<li>Unstacking gives each version back exactly what it had.</li>
</ul>
