<p class="lead">Two steps, so a big library shows up in seconds.</p>
<ul>
<li><b>Scan</b> finds the project files — on launch, and whenever you press <kbd>Ctrl</kbd> <kbd>R</kbd>.</li>
<li><b>Deep Scan</b> reads inside them: tempo, key, DAW version, tracks, plug-ins, MIDI. Run it from the side rail, or <b>Extract</b> on one project. It isn't automatic: on a cloud drive, reading means downloading.</li>
</ul>
<div class="tip">What each DAW gives up: <a href="/guide/metadata-extraction/">What's read from each DAW</a>. A value read wrong can always be typed over.</div>
